## !!! moved to [codeberg](https://codeberg.org/david-baierl/devcontainer)
this repository was moved to codeberg and is no longer continued on github

### install

```sh
git submodule add git@github.com:david-baierl/devcontainer.git .devcontainer
```

ensure following `.gitconfig` settings are enabled

```toml
[submodule]
	recurse = true
	stickyRecursiveClone = true
```
